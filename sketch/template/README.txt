Sketch - Laurence Who Studio
Venues, stages, scenography and architecture, built on Blender (GPL).

INSTALL (Windows)
1. Install Blender 5.2 from blender.org (free).
2. Open Blender > File > Defaults > Install Application Template... > choose ben.zip
3. File > New > Sketch  (or double-click "Sketch.bat")

SKETCHUP SHORTCUTS (in the 3D view)
Space Select        L Line          R Rectangle     C Circle      A Arc
P Push/Pull         F Offset        M Move          Q Rotate      S Scale
T Tape Measure      B Paint Bucket  E Eraser        G Make Group
O Orbit             H Pan           Z Zoom          Shift+Z Zoom extents
Shift+W Walk        Arrow keys lock an axis (right = red X, left = green Y, up = blue Z)
While drawing, type sizes and press Enter: "4,3" for a 4 x 3 m rectangle,
"1.5" for a circle radius, "2" for a Push/Pull distance.

The Sketch tab in the right sidebar (N) has every tool plus Venue,
Scenography, Model and View panels.
