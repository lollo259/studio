# Studio

Free apps for musicians, by Laurence Who.

| App | What it is | Based on |
|---|---|---|
| **Score** | Notation. *Amusing scores.* | MuseScore Studio |
| **Tape** | Recording, editing, mixing, video. | Audacity 4 |
| **Sketch** | Stage and space design. *Gotta sketch them all.* | Blender |
| **Muse** | A chat with your muse. | — |

Each app lives in its own folder. Shared design and settings live in `shared/`.

Score and Tape are independent versions of MuseScore Studio and Audacity and are not affiliated with or endorsed by MuseScore Limited or Muse Group. All code is GPL-3.0, like the projects it comes from.
