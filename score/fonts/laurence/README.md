# Laurence (private music font)

Put these three files here to build Muse with Laurence as the default music font:

- `Laurence.otf`          — SMuFL music font
- `LaurenceText.otf`      — matching text font (family name "Laurence Text")
- `laurence_metadata.json` — SMuFL metadata exported with the font

If the files are missing, Muse builds normally with Leland as the default.
